# Security

ZOOMRIYA ID signs in every member of a family to every ZOOMRIYA app, so we
treat security reports as the most important thing we receive.

## Reporting a vulnerability

Report it privately through GitHub: **Security › Report a vulnerability** on
this repository. Please don't open a public issue, pull request or discussion
about it.

Include what you found, how to reproduce it, and what an attacker could do with
it. A proof of concept helps but isn't required.

## What happens next

- We acknowledge your report within 3 working days.
- We tell you whether we can reproduce it, and keep you updated until it's
  fixed.
- We agree a disclosure date with you, normally within 90 days of the report,
  sooner once a fix has shipped.
- We credit you in the advisory, unless you'd rather not be named.

## Scope

In scope: everything in this repository: signing in and out, sessions and
tokens, passwords, accounts, families and their roles, guardians and child
accounts, and the API the apps use, including ZOOMRIYA ID where ZOOMRIYA runs
it.

Please don't test against other people's boxes or accounts, run denial-of-service
tests against ZOOMRIYA's servers, or access data that isn't yours. Use your own
box, or a ZOOMRIYA ID you run yourself.
